恒外压下气缸气体的不可逆膨胀与压缩：分子视角

这是一个二维硬球气体的教学演示。右侧灰色板是活塞，红色箭头表示恒定外压。 外压小于初始参考压强时发生膨胀，外压大于初始参考压强时发生压缩。 绿色和紫色曲线表示左侧区域与活塞附近区域的局部压力估算，用于说明非平衡过程中不同区域的压力可以不同。 下方过程图的纵轴尺度在一次演示中保持固定，不再随时间自动改变，因此更适合课堂观察。速率分布图的横轴也在一次演示中固定；过程图中另外加入了初始体积 V₀ 的参考线，便于比较“回到初始状态”与否。新版还加入功、热和内能变化的跟踪图，并在右侧说明各参数的教学计算方法。

理论说明与计算方法

本网页是一个二维硬球气体的教学模型，用来帮助学生理解恒外压下快速膨胀或压缩时， 微观分子运动、局部压力、速率分布、功、热与内能变化之间的关系。当前版本使用较多粒子、较重活塞，并在释放活塞前进行固定体积预平衡；局部压力估算用预平衡后的 P₀ 进行标定，以减少有限粒子涨落造成的系统性偏移。所有量均为 二维约化单位，用于定性教学，不用于真实气体定量计算。

以下内容整理为折叠式讲义。点击每一节标题可展开或收起。

1. 模型与动力学

气体由较多相同硬球粒子组成，粒子之间以及粒子与壁面之间发生弹性碰撞。 右侧边界是可移动活塞。程序先在固定活塞位置下预平衡气体，再用预平衡后的 NkT/V 作为初始参考压强 P0，并用它标定局部压力估算。外界对活塞施加恒定外压 Pext。活塞左侧是气体体积 V(t)=xp(t)H，其中 xp 是活塞位置，H 是二维气缸高度。

活塞运动由活塞附近局部压力、恒外压和阻尼共同决定。这个设置不是严格研究级分子动力学， 但可以展示边界运动如何通过分子碰撞改变气体能量。

2. 平均动能与动能温度估算

对第 i 个粒子，平动动能为 Ki=m(vxi2+vyi2)/2。 总动能为 K=ΣKi。

本演示取 kB=1。二维硬球气体每个粒子有两个平动自由度， 因而在平衡或局部平衡条件下有 <K>/N=T。 网页中显示的“动能温度估算”按 Tkin=K/N 计算。

3. 内能

硬球理想气体没有连续分子间势能项，因此这里的气体内能近似取为平动动能： U(t)=K(t)。 内能变化为 ΔU=U(t)-U(0)。

如果以后改成 Lennard-Jones 气体，则内能应写成 U=K+Φ，其中 Φ 是分子间势能。

4. 速率分布

粒子速率定义为 v=(vx2+vy2)1/2。 右侧速率图统计当前所有粒子的速率直方图。

灰色参考曲线是二维 Maxwell 型速率分布： f2D(v)=(m/T)v exp[-mv2/(2T)]。 该分布严格适用于平衡态或局部平衡态。快速膨胀或压缩时，分布可能明显偏离这条参考曲线。

5. 局部压力与“压力无法定义”的含义

平衡态中，气体压力可以作为一个单一热力学状态量。但在快速膨胀或快速压缩过程中， 气体内部不同区域尚未达到机械平衡，因此不同位置的动量通量可以不同。

网页中显示两个局部压力估算值： Pleft 表示气缸左侧区域的局部压力估算， Ppiston 表示活塞附近区域的局部压力估算。 它们采用局部动量通量近似： Px≈Σm(vx-<vx>)2/A， 并做了时间平滑，避免单帧碰撞数太少导致数值跳变。

当 Pleft 与 Ppiston 明显不同时，说明体系处于非平衡状态。 此时可以谈局部压力或边界动量通量，但不能把整个气体严格赋予一个单一的 Pgas。

6. 恒外压边界功

本演示采用化学热力学习惯符号： ΔU=q+w。 恒外压不可逆体积功按宏观热力学公式计算： wext=-Pext[V(t)-V0]。

膨胀时 V(t)>V0，所以 wext<0，表示气体对外做功； 压缩时 V(t)<V0，所以 wext>0，表示外界对气体做功。

7. 活塞碰撞功

网页还显示一个教学辅助量 wcoll，称为活塞碰撞功。 它逐次累计分子与运动活塞碰撞前后气体分子动能的变化： wcoll=ΣΔKcollision。

这个量用于展示移动边界如何通过分子碰撞把机械能传递给气体或从气体带走能量。 它不是标准热力学状态函数，也不一定与 wext 完全相同。有限质量活塞、阻尼和明显非平衡都会造成二者差异。

8. 热浴、Boltzmann 分布与速度重标定

严格的等温体系应当对应正则系综。也就是说，在平衡态下，体系状态的概率应服从 Boltzmann 权重： P(Γ)∝exp[-H(Γ)/(kBT0)]。 对理想硬球气体而言，速度部分对应 Maxwell-Boltzmann 分布。二维情况下，单个速度分量应近似满足 f(vx)∝exp[-mvx2/(2kBT0)]， 速率分布则为 f2D(v)=(m/kBT0)v exp[-mv2/(2kBT0)]。

从统计力学角度看，温度控制的目标不只是让某一时刻的平均动能等于目标值， 而是让体系在长期采样中给出正确的 Boltzmann/Maxwell-Boltzmann 分布。 真实或严格的 MD 恒温方法通常使用 Langevin thermostat、Andersen thermostat、Nosé-Hoover thermostat 或随机速度重标定等方法，使体系在合适条件下采样正则系综。

对非平衡体系而言，“温度”本身也需要谨慎理解。严格的热力学温度通常定义在平衡态或局部平衡态中。 如果体系处于快速膨胀或快速压缩过程，速度分布可能不是 Maxwell-Boltzmann 分布， 不同区域甚至不同方向的动量涨落也可能不同。这时不能总是给整个体系赋予一个单一、严格的温度。

在分子模拟中，常用一个动能温度估算来表征平均平动动能： Tkin=K/N。 这个量适合用来观察能量变化趋势，但在明显非平衡时，它只是一个由平均动能定义的估算量， 不一定等同于严格热力学温度。必要时还可以定义局部动能温度、方向温度 Tx、Ty， 或温度张量，而不是一个全局标量。

当前网页使用的是更简单的确定性速度重标定，目的是教学演示，而不是严格正则系综采样。 程序先计算当前总动能 K 和当前动能温度估算 Tkin=K/N，再把所有分子速度乘以 λ=(T0/Tkin)1/2。 这样速度变为 v′=λv，动能变为 K′=λ2K，从而把当前平均动能拉回目标值附近。

这个方法的物理含义可以理解为：热浴在每一步人为地向气体补充或移走一部分动能， 使全局动能温度估算保持在 T0 附近。 程序把速度重标定造成的动能变化 ΔKbath=K′−K 累计为热量 q。 若 ΔKbath>0，表示热浴向气体供热； 若 ΔKbath<0，表示气体向热浴放热。

需要特别说明，简单速度重标定会压制真实正则系综中的能量涨落，也不会自动保证速度分布严格服从 Maxwell-Boltzmann 分布。它只保证平均动能被控制在目标值附近。因此，在本网页中， “等温热浴（简化重标定）”应理解为教学近似的温度控制器，用于帮助学生理解等温膨胀/压缩中 功与热的能量收支，而不是严格的正则系综模拟。

在本教学模型中，更适合用 ΔU≈q+wcoll 检查微观能量收支；同时用 wext=-PextΔV 连接宏观不可逆体积功公式。

9. 全过程热量如何得到

热量 q 不是状态函数，不能只由初态和终态唯一决定； 它是过程中由于热接触而传递的能量。因此，本网页中的总热量是沿模拟轨迹逐步累计得到的。

若选择绝热壁，定义上气体与外界没有热交换， 因而整个过程的热量为 qtotal=0。 这时气体内能变化主要来自活塞碰撞功： ΔU≈wcoll。 膨胀时，分子撞到向外运动的活塞后通常变慢，气体动能减少； 压缩时，分子撞到向内运动的活塞后通常变快，气体动能增加。

若选择等温热浴（简化重标定），程序在每一步计算速度重标定前后的动能变化： Δqi=K′i−Ki。 全过程热量就是这些小步热量的累加： qtotal=ΣiΔqi=Σi(K′i−Ki)。 因此，网页中橙色曲线显示的是从初始时刻开始累计的热量。

对理想硬球气体而言，内能主要由平动动能决定。若等温条件维持得较好， ΔU 通常较小。等温膨胀时气体对外做功，为维持平均动能， 热浴通常向气体供热，因此 q>0； 等温压缩时外界对气体做功，热浴通常带走多余能量，因此 q<0。

网页中同时给出两个功的口径。宏观恒外压边界功为 wext=−Pext(Vf−V0)。 若用宏观第一定律口径估算终态热量，可写作 qmacro=ΔU−wext。 另一方面，网页中的微观能量收支更适合用 qtotal≈ΔU−wcoll 来检查，其中 wcoll 是活塞通过分子碰撞传递给气体的机械能。

判断“过程结束”时，应等到体系接近新的稳定状态，例如活塞速度接近零、 左侧局部压力与活塞附近局部压力接近、速率分布重新接近 Maxwell 型参考曲线。 这时读取 Vf、 ΔU、w 和 q，才更接近热力学终态比较。

恒容过程理论说明

恒容（等容/定容）过程中，系统体积保持不变，因此没有体积功。

1. 恒容过程的基本特征

体积恒定 V = V₀ → w = −∫Pext dV = 0 → ΔU = qV

二维单原子理想气体：U = K = NkT → ΔU = Nk(Tf − Ti)，CV = Nk

状态方程：P = NkT/V₀ → P ∝ T（压强随温度线性变化）

2. 可逆 vs 不可逆恒容过程

不可逆恒容：系统与温度为 Ttarget 的热库突然接触（有限温差），通过有限速率热传导趋向平衡。过程中存在有限温差 → ΔSuniv > 0。

可逆恒容：热浴温度从 T₀ 开始以极微步长线性扫描至 Ttarget。每步充分弛豫，系统始终保持近平衡。Tbath 始终与系统仅差 dT → ΔSuniv ≈ 0。

两者终态相同（Tf, V₀ 确定），但路径熵产生不同。

3. 能量关系

恒容下 w ≡ 0，因此 ΔU = qV。内能的变化完全由热交换引起。

二维理想气体：ΔU = Nk(Tf − Ti)。加热时 Tf > Ti → ΔU > 0, q > 0；冷却时相反。

第二部分：可逆准静态过程 — 与不可逆过程的对比

可逆过程理论基础

可逆过程是热力学中极为重要的理想模型。一个过程被称为可逆，当且仅当系统与环境可以在不留下任何净效应的前提下，沿着完全相同的路径逆向返回初始状态。实现可逆过程的必要条件包括：过程无限缓慢（准静态）、系统内部始终处于平衡态、无摩擦等耗散效应。

1. 准静态过程与可逆性的关系

准静态（quasi-static）过程是指过程进行得无限缓慢，系统在每一步都无限接近平衡态。准静态过程是可逆过程的必要条件，但不是充分条件——例如，准静态的等温膨胀如果有摩擦，仍然不可逆。

在本演示中，我们通过位置控制而非力控制来驱动活塞：活塞每一步只移动极微小的距离 dV = (Vtarget - V0) / Nsteps。步数 Nsteps 越大（最多可达 3000），过程越接近准静态极限，也越接近真正的可逆过程。

2. 可逆体积功与最大功原理

可逆过程中，系统压强始终与环境压强相差无穷小：Psys = Pext ± δP。因此可逆体积功为：

wrev = -∫Pgas dV

对于等温理想气体（二维）：wrev = -NkT ln(Vf/Vi)。

最大功原理：在给定初态和终态之间，系统在可逆过程中对外做的功最大（膨胀），外界对系统做的功最小（压缩）。恒外压不可逆过程的功总是小于可逆功的绝对值（膨胀时）或大于可逆功的绝对值（压缩时）。

3. 弛豫步数与可逆性的关系

在本模拟中，"弛豫步数"控制活塞每移动一步后，粒子有多少时间来重新达到局部平衡。弛豫步数越多 → 过程越慢 → 越接近可逆极限。

学生实验建议：

  • 保持目标体积和总步数不变，只改变弛豫步数（如 0/2/5/15），观察 MD 模拟结果的变化
  • 观察 w_rev (MD) 是否随弛豫步数增加而趋近解析值 -NkT₀ln(V_f/V₀)
  • 观察 ΔS_univ 是否随弛豫步数增加而趋近 0
  • 弛豫步数 = 0 时，即使活塞是位置控制的（准静态移动），过程仍然趋近不可逆极限——因为粒子没有时间重新建立平衡，速度分布严重偏离 Maxwell-Boltzmann 分布
  • 这说明了"准静态"（无限缓慢）是可逆性的必要条件：仅有位置控制是不够的，还需要足够的时间让系统在每个中间状态达到平衡

物理图像：弛豫步数本质上模拟了过程的时间尺度。当弛豫步数很大时，每一步活塞微移后粒子都有充分时间碰撞并重新建立局部平衡分布，系统始终无限接近平衡态，过程趋近可逆。反之，弛豫步数不足时，粒子分布滞后于体积变化，造成不可逆的熵产生。
