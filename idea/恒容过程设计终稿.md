# 恒容过程 — 设计终稿

## 一、顶层架构：过程类型切换器

### 1.1 位置
标题正下方，所有控件之上。

### 1.2 结构
- 两个互斥按钮：`恒外压（体积功）` / `恒容（变温）`
- 默认选中「恒外压」，高亮当前模式。

### 1.3 全局状态变量
- `processMode`: `'isobaric'` | `'isochoric'`

### 1.4 模式语义
| 模式 | 上块画布 | 下块画布 |
|------|---------|---------|
| 恒外压 | 不可逆恒外压（力驱动活塞） | 可逆等温（位置控制活塞） |
| 恒容 | 不可逆恒容（温度驱动，活塞固定） | 可逆恒容（温度线性扫描，活塞固定） |

### 1.5 切换行为
1. 停止所有动画（`running = false; rev_running = false`）
2. 清空上下两块 trace 数据
3. 调用对应模式的 `initialize()` 和 `resetReversible()`
4. 更新全部控件显隐和理论卡片

## 四、不可逆恒容（上块）算法

### 4.1 物理图像
活塞被插销固定 → $V \equiv V_0$。系统与温度为 $T_\text{target}$ 的热库突然接触（有限温差），通过有限速率的热传导趋向平衡。

### 4.2 核心约束
- `xP` = 初始位置（恒定），`vP = 0`
- `Pext`、阻尼均不参与
- 活塞视为普通固定硬壁（与左壁等价）

### 4.3 每步操作
1. 粒子自由飞行 + 粒子间碰撞 + 壁碰撞
2. **温和速度重标定**（向 $T_\text{target}$ 弛豫）：
 - `λ = 1 + rate × (√(T_target / T_current) − 1)`，其中 `rate = 0.3`
3. 累计热量：`q += K_after − K_before`（即恒温器注入/抽走的动能）
4. `workMicro` **强制置零**（防御性编程）
5. 记录 $P \leftarrow NkT/V$、$T_\text{kin}$ 到 trace

### 4.4 终态
$T_\text{kin} \approx T_\text{target}$，$P \leftarrow P_0 \times (T_\text{target}/T_0)$。

### 4.5 能量收支预期
$w \equiv 0$，$q = \Delta U$，$\Delta U = Nk(T_f - T_i)$。

## 五、可逆恒容（下块）算法

### 5.1 物理图像
热浴温度从 $T_0$ 开始，以极微步长线性扫描至 $T_\text{target}$。每步充分弛豫，系统始终保持近平衡。

### 5.2 核心约束
- 复用 `revSim` 对象，`revSim.xP` 固定
- $w_\text{rev} \equiv 0$（活塞固定，无边界位移功）

### 5.3 每步操作
1. **计算滑动靶温度**：
 - `T_step = T0 + (T_target − T0) × (currentStep / totalSteps)`
2. 运行 `nRelaxPerStep` 次弛豫子步：
 - 粒子运动 + 碰撞（固定活塞）
3. **温和恒温器以 `T_step` 为目标进行弛豫**
 -  **关键：** 不可复用 `gentleThermostatRev(revSim.initialTemp0, ...)`，必须传入滑动 `T_step`
4. 记录 $P \leftarrow NkT/V$ 到 trace

### 5.4 能量关系
- $q_\text{rev} = \Delta U = Nk(T_f - T_i)$（累计自恒温器能量变化）
- $w_\text{rev} = 0$

### 5.5 可逆性条件
`T_step` 步长足够小 + `nRelaxPerStep` 足够大 → 系统始终近似平衡，$\Delta S_\text{univ} \approx 0$。

## 九、实现注意事项（防坑清单）

| # | 事项 | 说明 |
|---|------|------|
| 1 | `workMicro` 强制归零 | 恒容分支中显式 `workMicro = 0`，防御 vP=0 的边界情况 |
| 2 | 可逆恒容恒温器目标 | 必须传入**滑动 `T_step`**，不可复用 `revSim.initialTemp0` |
| 3 | 活塞碰撞逻辑 | 恒容下活塞视为固定硬壁，碰撞时速度反向，不累计做功 |
| 4 | 模式切换清理 | 依次：停止动画 → 清空 trace → 调用初始化 → 更新控件显隐 |
| 5 | V₀ 图例合并 | 恒容下 V 线与 V₀ 线重合，图例合并为"V=V₀（恒容）" |
| 6 | `tempRatioSlider.onchange` | 值变化时触发初始化（与 `posSlider.onchange` 一致） |
| 7 | 一键按钮对称 | 两套按钮组按 `processMode` 互斥显示，不可同时可见 |
| 8 | 统计面板标签 | 恒容下可显示提示："预期 P_left ≈ P_piston（平衡态）" |
