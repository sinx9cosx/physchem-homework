## 核心问题：$\Delta A$ 公式的符号错误

### 当前写法

```javascript
function deltaA() {
    const T = temperature();
    const V = volume();
    const T0 = initialTemp0;
    const V0 = initialVolume0;
    if (V <= 0 || V0 <= 0 || T <= 0 || T0 <= 0) return 0;
    return -N * (T * Math.log(V) - T0 * Math.log(V0))
           + N * (T * Math.log(T) - T0 * Math.log(T0))        // ← 符号错
           + N * (T - T0) * (1 - Math.log(N));                // ← 两项符号都错
}
```

## 🔧 修正代码

```javascript
function deltaA() {
    const T = temperature();
    const V = volume();
    const T0 = initialTemp0;
    const V0 = initialVolume0;
    if (V <= 0 || V0 <= 0 || T <= 0 || T0 <= 0) return 0;
    return -N * (T * Math.log(V) - T0 * Math.log(V0))
           - N * (T * Math.log(T) - T0 * Math.log(T0))          // ← 改 + 为 -
           + N * (T - T0) * (Math.log(N) - 1);                  // ← 1-ln(N) → ln(N)-1
}
```

可逆模块的 `revDeltaA()` 同理修改。
